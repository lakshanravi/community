# MarketSync – Economic Center Management System

A comprehensive **web-based management system** developed for managing Economic Centers. This system simplifies the management of tenant records, shop allocations, vehicle ticketing, invoicing, and financial operations—all in one centralized platform.

## 🚀 Features

- **Tenant & Shop Management** – Register tenants and allocate shops with full relationship tracking.
- **Invoice Processing** – Generate, update, and manage tenant invoices based on shop rentals and services.
- **Vehicle & Ticket Tracking** – Manage vehicle entries and generate tickets with associated billing.
- **Financial Dashboard** – View revenue summaries, track transactions, and monitor outstanding balances.
- **Authentication** – Admin login system with protected routes and secure access.
- **Responsive UI** – Clean and intuitive design using Tailwind CSS for all screen sizes.
